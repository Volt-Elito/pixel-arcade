## 🧐 About

**Pixel-Arcade** is a centralized web platform designed to let users instantly discover and play fun, casual games directly inside their web browsers with zero downloads or installations required. 

Most of the games featured on the platform are sourced from open-source repositories across the GitHub community, bundled together into a clean, responsive, and easy-to-navigate user interface. The site is optimized for performance and globally distributed using Cloudflare's free tier hosting.

---

## ✨ Features

* **Instant Play:** Zero installation, zero lag—launch and play straight from any modern desktop or mobile browser.
* **Open-Source Collection:** Aggregates engaging, community-driven open-source mini-games.
* **Responsive UI:** Clean and adaptive layout designed to look great on various screen sizes.
* **Lightning-Fast Edge Delivery:** Served globally via Cloudflare infrastructure for high availability and minimal latency.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Hosting / CDN:** Cloudflare Pages / Static Hosting
